# AI Lab 页面现代化重构设计方案

## 概述

将 AI Lab 页面从当前"太丑"的状态重构为**轻玻璃进化版**设计风格。核心哲学：玻璃质感只在需要时才被感知，大量留白、极度克制的装饰、优雅从容的节奏感。

## 设计语言

### 色彩系统

| Token | 浅色模式 | 深色模式 | 用途 |
|-------|----------|----------|------|
| `--bg-base` | `#FFFFFF` | `#111112` | 页面背景 |
| `--bg-glass` | `rgba(255,255,255,0.92)` | `rgba(17,17,18,0.85)` | 玻璃面板透明度 85-92% |
| `--border-color` | `rgba(0,0,0,0.04)` | `rgba(255,255,255,0.08)` | 边框 1px |
| `--primary` | `#1677ff` | `#1677ff` | 主题蓝 |
| `--primary-grad` | `linear-gradient(135deg, #1677ff 0%, #722ed1 100%)` | 同左 | 渐变强调 |
| `--text-main` | `#1f1f1f` | `#e6e6e6` | 主文字 |
| `--text-sec` | `#8c8c8c` | `#858585` | 次文字 |

### 动效规范

| 动效 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 侧边栏展开/收起 | 350ms | `cubic-bezier(0.4, 0, 0.2, 1)` | 带轻微 overshoot 弹性 |
| 消息出现 | 400ms | `ease-out` | `translateY(12px) → 0, opacity 0 → 1` |
| 输入框 focus 光晕 | 200ms | `ease-out` | 边框渐变 + 3px 光晕扩散 |
| Hover 态 | 150ms | `ease-out` | 微妙上浮或光晕 |

### 字体 & 空间

- **字体栈**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial`
- **基础字号**: 15px
- **间距网格**: 8px 基准
- **组件内边距**: 16-20px
- **区块间距**: 24-32px

### 侧边栏行为
- **默认收起**：仅 Header 有 Toggle 按钮
- **展开时**：340px 宽，滑入动画 350ms，背景添加细微遮罩
- **收起时**：平滑滑出，遮罩消失，聊天区自动扩展

## 组件规范

### Header
- 高度：56px（原 64px）
- Logo 图标：28px（原 32px）
- Logo 文字：14px（原 16px）
- 按钮：纯图标 + tooltip，Ghost 风格
- 侧边栏 Toggle 按钮在中间位置

### 消息气泡
- 圆角：20px（原 16px）
- 内边距：16px 18px
- 玻璃效果：背景透明度 92%，边框 1px 0.04 透明度
- User 消息：背景渐变为纯 primary 色，纯白文字
- Bot 消息：玻璃效果，左对齐
- 最大宽度：85%
- 间距：消息之间 32px

### 悬浮输入框
- 整体圆角：24px（原 20px）
- 背景透明度：95%（几乎不透明，边缘有细微玻璃感）
- 输入框 max-width：800px
- Focus 时：边框变为渐变色 `0 0 0 3px` 光晕
- Shift+Enter 提示：更小的灰色标签

### 侧边栏面板
- 宽度：340px
- 玻璃透明度：88%
- 卡片背景透明度：95%，圆角 16px
- Setting 分组间距：24px
- Pro-tip 卡片：淡蓝色渐变边框（非纯色背景）

### 装饰背景
- 点阵网格：透明度从 0.08 降到 0.03
- 渐变光晕：更淡，仅在右上角若有若无
- 深色模式：渐变改为 `#06b6d4 → #8b5cf6`

## 深色模式适配

| 元素 | 浅色 | 深色 |
|------|------|------|
| 玻璃透明度 | 85-92% | 75-85% |
| 边框透明度 | 0.04 | 0.08 |
| 背景渐变 | 蓝紫 | 青色系 |

## 实现清单

1. 更新 CSS 变量系统（颜色、透明度、动效时间）
2. 重构 Header（高度、按钮、Toggle 位置）
3. 重构消息气泡（圆角、透明度、User/Bot 区分）
4. 重构悬浮输入框（圆角、focus 效果）
5. 实现侧边栏可收起逻辑（动画、状态管理）
6. 精简装饰背景（降低点阵和渐变透明度）
7. 适配深色模式
8. 测试所有交互状态
