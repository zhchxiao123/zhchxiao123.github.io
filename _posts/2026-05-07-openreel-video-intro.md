## 一、产品定位与核心价值

### 1.1 开源 CapCut 替代品

OpenReel Video 是一款完全运行在浏览器中的专业视频编辑器，被称为「开源 CapCut 替代品」。它打破了传统视频编辑软件需要本地安装的限制，让用户可以直接在浏览器中进行专业级的视频创作。

![OpenReel 官网首页](/assets/img/openreel/01-homepage.png)

### 1.2 核心价值主张

| 特性 | 说明 |
|------|------|
| **100% 客户端运行** | 视频永不离开设备，无需上传到云端 |
| **无需安装** | 直接打开浏览器即可使用 |
| **隐私保护** | 完全本地处理，数据不经过第三方服务器 |
| **开源免费** | MIT 许可证，无订阅费用，无水印 |
| **专业功能** | 多轨道时间线、GPU 加速、4K 支持 |

### 1.3 竞品对比

| 维度 | OpenReel | CapCut | Adobe Premiere |
|------|----------|--------|----------------|
| 运行方式 | 浏览器端 | 桌面/移动端 | 桌面端 |
| 安装需求 | 无 | 需要 | 需要 |
| 价格 | 免费开源 | 免费（有付费功能）| 订阅制 |

## 二、安装与运行

### 2.1 快速体验

| 方式 | 说明 |
|------|------|
| **在线体验** | 直接访问 https://openreel.video |
| **本地运行** | 需要 Node.js 18+ 和 pnpm |

### 2.2 本地安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/Augani/openreel-video.git

# 2. 进入目录
cd openreel-video

# 3. 安装依赖
pnpm install

# 4. 启动开发服务器
pnpm dev

# 5. 打开浏览器访问
# http://localhost:5173
```

### 2.3 系统要求

| 要求 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 浏览器 | Chrome/Edge 94+、Firefox 130+、Safari 16.4+ | 最新版本 |
| 内存 | 4GB | 8GB+ |
| 显卡 | 集成显卡 | 独立显卡（4K 编辑）|
| 处理器 | 多核 CPU | 现代多核 CPU |

## 三、视频编辑核心能力

### 3.1 多轨道时间线

OpenReel 提供无限数量的视频、音频、图片、文字和图形轨道。这种专业级的时间线设计让复杂项目的编排变得轻而易举：

- **无限轨道**：不受数量限制，自由叠加素材
- **拖拽排序**：直观的拖拽操作调整素材顺序
- **轨道管理**：显示/隐藏、锁定、重排序

![OpenReel 编辑器主界面](/assets/img/openreel/03-editor-main.png)

编辑器界面一览：

![编辑器界面概览](/assets/img/openreel/04-editor-clean.png)

### 3.2 帧级精度编辑

专业视频编辑的核心是精确控制每一帧。OpenReel 提供：

| 编辑功能 | 说明 |
|----------|------|
| 帧级定位 | 在时间线精确到单帧的定位 |
| 剪切 (Cut) | 快速将素材一分为二 |
| 裁剪 (Trim) | 调整素材的入点和出点 |
| 分割 (Split) | 在任意位置分割素材 |
| 涟漪删除 (Ripple Delete) | 删除后自动填补空隙 |

### 3.3 转场效果

内置多种专业转场效果，让视频过渡更加自然流畅：

- **交叉淡化 (Crossfade)**：平滑的颜色过渡
- **闪黑/闪白 (Dip to Black/White)**：戏剧性的场景切换
- **擦拭 (Wipe)**：方向性切换效果
- **滑动 (Slide)**：素材滑入滑出

### 3.4 视频特效

丰富的视频特效库满足各种创意需求：

| 特效类别 | 具体效果 |
|----------|----------|
| 基础调整 | 亮度、对比度、饱和度 |
| 模糊效果 | 高斯模糊、动态模糊 |
| 锐化 | 增强画面细节 |
| 光效 | 发光 (Glow)、暗角 (Vignette) |
| 高级 | 色度键 (Chroma Key) 抠像 |

### 3.5 混合模式

支持多种图层混合模式，实现创意叠加效果：

- **Multiply**：正片叠底
- **Screen**：屏幕模式
- **Overlay**：叠加模式
- **Add/Subtract**：加法/减法混合

### 3.6 速度控制

灵活的视频播放速度调节：

- **变速范围**：0.25x 到 4x
- **音频音调保持**：变速时保持音频音高不变
- **曲线变速**：非匀速的速度变化

### 3.7 裁剪与变换

完整的二维/三维变换能力：

- **位置调整**：精确控制素材位置
- **缩放**：自由缩放素材尺寸
- **旋转**：任意角度旋转
- **3D 透视**：带有透视效果的变换

## 五、音频处理能力

### 5.1 多轨混音

专业级的音频混音功能：

- **无限音轨**：可叠加多个音频文件
- **实时混音**：实时混合各轨道音频
- **独立控制**：每个轨道独立的音量控制

### 5.2 波形可视化

直观的音频波形显示：

- **可视化编辑**：在波形上直接编辑
- **精确裁剪**：根据波形定位裁剪点
- **静音检测**：自动识别静音区域

### 5.3 专业音效

丰富的音频效果器：

| 效果类型 | 说明 |
|----------|------|
| EQ 均衡器 | 调整音频频段 |
| 压缩器 | 控制动态范围 |
| 混响 | 空间效果 |
| 延迟 | 回声效果 |
| 合唱 | 加厚音色 |
| 镶边 | 经典镶边效果 |
| 失真 | 音频失真效果 |

### 5.4 音量与声像

- **音量曲线**：每个片段独立的音量包络
- **淡入淡出**：音频头尾的渐变
- **声像控制**：左右声道平衡

### 5.5 节拍检测

智能节拍分析功能：

- **自动标记**：根据音频自动生成节拍标记点
- **与音乐同步**：让视频动作与音乐节拍同步
- **BPM 检测**：自动识别歌曲速度

### 5.6 音频闪避

智能音频闪避 (Audio Ducking)：

- **对话优先**：自动降低背景音乐音量
- **阈值可调**：自定义触发阈值
- **过渡平滑**：自然的音量变化曲线

### 5.7 降噪

三段式降噪系统：

- **谐波降噪**：处理音调性噪声
- **宽带降噪**：消除持续性噪声
- **低频降噪**：去除隆隆声等低频噪声

## 六、色彩管理

### 6.1 色彩轮

专业调色的核心工具：

- **Lift（暗部）**：控制阴影区域
- **Gamma（中间调）**：调整中间调
- **Gain（亮部）**：控制高光区域

### 6.2 HSL 调整

精细的色相、饱和度、明度控制：

- **色相调整**：改变颜色倾向
- **饱和度**：控制颜色鲜艳程度
- **明度控制**：调整明暗程度

### 6.3 曲线编辑器

专业的曲线调色工具：

- **RGB 曲线**：整体亮度调整
- **单通道曲线**：分别调整红、绿、蓝通道
- **曲线预设**：常用曲线效果一键应用

### 6.4 LUT 支持

支持 3D LUT 颜色查找表：

- **导入 LUT**：加载第三方 LUT 文件
- **内置预设**：多种风格预设可选
- **强度控制**：调节 LUT 效果强度

### 6.5 内置预设

一键应用的调色预设：

- **电影风格**：专业电影色调
- **复古风格**：怀旧感色调
- **小清新**：明亮的日系风格
- **自定义**：保存自己的调色设置

## 七、导出与输出

### 7.1 视频格式

支持多种专业视频编码：

| 格式 | 编码 | 适用场景 |
|------|------|----------|
| MP4 | H.264/H.265 | 通用兼容性 |
| WebM | VP8/VP9/AV1 | 网络优化 |
| ProRes | Proxy/LT/Standard/HQ/4444 | 专业后期 |

### 7.2 质量预设

快速选择输出质量：

- **4K @ 60fps**：最高质量
- **1080p**：全高清
- **720p**：高清
- **480p**：标清

### 7.3 自定义设置

高级用户可自定义：

- **码率控制**：CBR 或 VBR
- **帧率选择**：24/25/30/60fps
- **色彩深度**：8bit/10bit
- **编码器选项**：细粒度控制

### 7.4 硬件加速

利用现代浏览器能力：

- **WebCodecs API**：硬件视频编码解码
- **GPU 加速**：WebGPU 渲染加速
- **快速导出**：比纯软件编码快数倍

### 7.5 AI 升频

智能分辨率提升：

- **WebGPU Shaders**：基于 GPU 的升频算法
- **细节增强**：提升低分辨率素材质量
- **4K 增强**：将 1080p 素材提升到 4K

### 7.6 音频导出

独立的音频导出选项：

- **MP3**：通用音频格式
- **WAV**：无损音频
- **AAC**：高质量压缩
- **FLAC**：无损压缩
- **OGG**：开源格式

### 7.7 图片序列

支持导出为图片序列：

- **JPG 序列**：压缩格式
- **PNG 序列**：无损格式
- **WebP 序列**：现代格式

### 7.8 进度追踪

导出过程中的实时反馈：

- **进度条**：直观显示导出进度
- **预估时间**：剩余时间估算
- **取消支持**：随时停止导出
